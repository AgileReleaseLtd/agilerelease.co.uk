# xpromo tiles

Pictures for the in-app "Try <game>" suggestions. Apps download each picture once and cache it by URL.

Never reuse a filename for a different picture. To change a picture, add a new file (for example roost-v3.png)
and point the list at the new URL. Keep the old file in place.

Format: 256 x 256 PNG, served at https://agilerelease.co.uk/xpromo/<name>.png
